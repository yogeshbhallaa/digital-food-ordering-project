# Java Dependencies

The original application uses third-party JAR dependencies in this directory.

They are intentionally not committed to Git because some of the libraries are large, especially JxBrowser.

Before running the project locally, restore the required libraries and configure them in the NetBeans/Ant project classpath.

Typical dependencies include:

- MySQL Connector/J
- JxBrowser 7
- Apache HttpClient / HttpCore
- Unirest
- JSON
- JWebServer
- Commons Codec / Logging

Use versions compatible with the original project or update the project dependencies as needed.
